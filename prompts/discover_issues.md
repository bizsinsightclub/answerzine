# 이슈 후보 찾기

지금 한국에서 사람들이 많이 보고 있는 영상 제목 목록을 준다.
여기서 **이슈가 될 만한 것**만 골라 내라. 새로 지어내지 말고, 목록에 있는 것만 묶어라.

## 이슈인 것과 아닌 것

- 이슈다: 여러 채널이 같은 사안을 반복해서 다룬다. 편이 갈리거나, 논쟁이 붙었거나, 며칠에 걸쳐 이어진다.
- 이슈가 아니다: 한 채널만 다룬 단발성 화제. 감동 미담, 동물 구조, 놀라운 클립, 일반적인 정보 전달.
- 제목이 자극적인 것과 이슈인 것은 다르다. 반복되는지만 본다.

## 규칙

- 8~12개를 낸다. 모자라면 모자란 대로 낸다.
- `keyword`는 유튜브 검색창에 그대로 넣어 쓸 말이다. 짧고 구체적이어야 한다. 문장이 아니다.
- `id`는 영문 소문자와 하이픈만 쓴다. 파일 이름으로 쓴다.
- `proper_nouns`에는 그 이슈에 나오는 인물·지명·기관 이름을 원형 그대로 적는다. 없으면 빈 배열.
- `mentions`는 이 사안을 다룬 영상이 목록에 몇 개나 있는지 센 수다. 점수가 아니라 개수다.
- `why`는 왜 이게 지금 반복되는지 한 줄. 25자를 넘기지 않는다.
- 특정 개인·집단을 향한 비하·혐오·차별 표현은 쓰지 않는다. 사안을 중립적으로 이름 붙인다.

## 출력 형식

JSON 배열만 출력한다. 앞뒤 설명문·코드 펜스 금지.

[
  {
    "id": "영문-소문자-하이픈",
    "keyword": "유튜브 검색어",
    "title": "이 이슈를 한 줄로",
    "why": "왜 지금 반복되는지 25자 이내",
    "proper_nouns": ["인물", "지명", "기관"],
    "mentions": 4
  }
]
