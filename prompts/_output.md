## 출력 형식

JSON 배열만 출력한다. 앞뒤 설명문·인사말·코드 펜스 금지.

{N_MIN}~{N_MAX}개를 만든다. 개수가 모자라도 억지로 채우지 않는다.

원소 하나가 후보 하나이며 키는 정확히 다섯 개다.

[
  {
    "candidate": "후보 표현",
    "mechanism": "{MECH}",
    "source_word": "빌려온 원본 단어",
    "active_word": "이슈에서 가져온 활성 단어",
    "one_line": "20자 이내 메모"
  }
]

- `one_line`은 설명이 아니라 메모다. 20자를 넘기지 않는다. 약한 후보를 설명으로 살리지 않는다.
- 후보에 점수·등급·순위를 붙이지 않는다.
- 제외 단어 목록에 있는 원본 단어는 쓰지 않는다.
