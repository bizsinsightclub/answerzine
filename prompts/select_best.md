# 하나 고르기

발산된 후보 전부를 준다. 그중 **하나**를 고른다.

이 일은 발산이 아니다. 발산은 이미 끝났고, 여기서는 편집자의 눈으로 하나를 집는다.

## 고르는 기준 — 뒤샹의 카테고리 전복

> 뒤샹은 변기를 서명 하나로 예술로 만들었다.
> 사물의 존재 지위를 바꾼 것이지, 사물을 예쁘게 만든 것이 아니다.

- 예쁜 것, 재치 있는 것, 말이 잘 굴러가는 것을 고르지 마라. 그건 망막적인 취향이다.
- 어떤 것의 **지위를 바꿔 버리는** 것을 골라라. 재난을 상품으로, 습관을 국가 의례로, 수치를 성물로, 결함을 문화재로.
- 그 재선언 이후의 세계가 진지하게 굴러가는 것이어야 한다. 농담으로 도망치는 것은 탈락이다.

## 심판 축 — 아래 셋에 걸리면 아무리 마음에 들어도 탈락

- **PREDICTABLE**: 처음부터 "그렇지." 소리가 나온다. 두 단어가 서로를 설명해 준다. 탈락.
- **FORCED**: 억지로 꿰맞췄다. 왜 이 둘인지 끝까지 안 풀린다. 탈락.
- **ALIEN**: 이슈를 아는 사람도 못 알아본다. 탈락.
- **STRANGE-BUT-USABLE**: 첫 반응이 "응?"이고, 이슈를 알면 "아."로 바뀐다. **이것만 살아남는다.**

0.5초 안에 낯설고, 그다음 1초에 알아보고, 그다음에 웃거나 서늘해져야 한다.

## 렌즈 붙이기

렌즈 목록을 함께 준다. 각 렌즈는 실존 인물의 분야와 **검증된 실제 발언**을 갖고 있다.

- 고른 키워드를 **실제로 해설할 수 있는 분야**의 렌즈를 하나 고른다. 유명해서 고르지 마라.
- 인용은 그 렌즈의 「실제 발언」 목록에서 **번호 하나를 짚는다** (`Q3` 이면 `3`).
  베껴 쓰지 마라. 번호만 주면 원문은 시스템이 그대로 가져다 붙인다.
- 목록에 없는 말을 지어내면 그것은 위조다. 절대 하지 마라.
- `quote_ko`에는 그 인용의 **한국어 번역**을 적는다. 원문이 이미 한국어면 그대로 옮긴다.
  출처 표기(`— 책 이름 [23]`)는 빼고 말만 옮긴다. 번역체를 남기지 마라 — 그 사람이 한국어로
  말했다면 어떻게 말했을지를 쓴다.
- 그 인용이 왜 이 키워드 밑에 놓이는지 한 줄로 잇는다. 25자 이내.

## 경계

- 특정 개인·집단을 향한 비하·혐오·차별로 읽히는 것은 아무리 세도 고르지 않는다.
- 이름을 붙이는 대상은 사람이 아니라 현상이다.

## 출력 형식

JSON 객체 하나만 출력한다. 앞뒤 설명문·코드 펜스 금지.

{
  "best": {
    "candidate": "고른 후보 그대로",
    "issue": "어느 이슈에서 나왔나",
    "mechanism": "mech_0X",
    "source_word": "빌려온 원본 단어",
    "active_word": "이슈에서 온 활성 단어"
  },
  "verdict": "STRANGE-BUT-USABLE",
  "why": "왜 이것인가. 뒤샹 기준으로 세 문장 이내. 무엇의 지위가 무엇으로 바뀌었는지 반드시 명시.",
  "reading": {
    "first": "0.5초에 뭐라고 읽히나",
    "then": "이슈를 알면 무엇으로 바뀌나"
  },
  "runners_up": [
    { "candidate": "아깝게 밀린 것", "why": "한 줄" }
  ],
  "lens": {
    "id": "LENS-0X",
    "quote_no": 3,
    "quote_ko": "그 인용을 한국어로 옮긴 것. 번역체 없이, 그 사람이 한국어로 말했다면 이랬을 문장.",
    "bridge": "이 인용이 왜 이 키워드에 붙나. 25자 이내."
  }
}

`runners_up`은 2~3개. 점수는 매기지 않는다. 순위가 아니라 '아깝게 밀린 것'일 뿐이다.
