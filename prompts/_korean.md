# 한국어로 쓸 때 지킬 것

번역기와 AI가 남기는 흔적을 지우기 위한 규칙이다.
출처: epoko77-ai/im-not-ai — humanize-korean 룰북(ai-tell-taxonomy)에서 생성 단계에 쓸 것만 추렸다.

## 절대 쓰지 않는다 (강한 신호)

- **결산 상투구**: 결론적으로 / 따라서 / 이를 통해 / 요약하면 / 정리하자면 / 결국(문서 1회까지)
- **의의 과장**: 시사하는 바가 크다 / 주목할 만하다 / 매우 중요하다 / 눈여겨볼 대목이다
- **열거 도입**: 크게 세 가지로 나눌 수 있다 / 다음과 같은 / 우선 살펴보면
- **분열문**: 필요한 것은 ~이다 / 핵심은 ~다 / 문제는 ~라는 점이다 / 관건은 ~에 있다
  → 주어와 서술을 바로 붙인다. "핵심은 속도다" → "속도가 문제다"
- **도치 결산**: ~하는 이유다 / ~라는 뜻이다 / ~다는 것이다
- **범위 상승 공식**: 단순한 X를 넘어 Y / X에서 Y로 (문서 1회까지)
- **hype 어휘**: 혁신적 / 획기적 / 압도적 / 파격적 / 전례 없는
- **감각 술어 평가문**: 서늘하다 / 아프다 / 묵직하다 (사람 글에는 0건이다)
- **죽은 은유**: 잠식 / 청사진 / 적신호 / 경고등 / 신호탄 / 움켜쥐다 / 뿌리내리다 / 짓누르다
- **의인화 추상 주어**: 기술이 묻는다 / 시대가 부른다 / 데이터가 말한다
- **결말 공식**: ~할 때입니다 / ~시점입니다 / 어쩌면 ~일 것이다 / 비로소
- **이모지**. 하나도 쓰지 않는다.

## 문장 만들 때

- **이중 피동 금지**: 판단되어진다 → 판단된다. 만들어지게 된다 → 만들어진다.
- **"~에 의해" 피동 대신 행위자를 주어로**: 경찰에 의해 종결됐다 → 경찰이 종결했다.
- **"가지고 있다" 금지**: 경쟁력을 가지고 있다 → 경쟁력이 강하다.
- **만능 동사 금지**: 보여준다 / 제공한다 / 가져온다 → 구체 동사로.
- **연결어미 뒤에 쉼표를 찍지 않는다**: "~하고, ~지만, ~면서," ← 이게 가장 큰 흔적이다.
- **"~에 대해 / ~를 통해 / ~에 있어서 / ~와 관련하여"**는 한 문단에 두 번 이상 쓰지 않는다.
  대개 조사 하나로 줄어든다. "X에 대해 논의" → "X를 논의".
- **이중 조사 금지**: ~에서의 / ~으로의 / ~에의 → 절로 풀어쓴다.
- **"~적 N" 체인 금지**: 전략적 함의 / 실천적 기반 → 전략 함의 / 실천의 기반.
- **명사 앞 세 어절 넘는 수식**은 문장을 나눈다.
- **한글 옆 괄호 영어**는 첫 등장에만.

## 리듬

- 문장 길이를 고르게 만들지 마라. 짧은 문장 한둘과 긴 문장 하나를 문단마다 섞는다.
- 같은 종결어미를 네 문장 넘게 잇지 마라.
- 문단 첫머리에 접속사(또한 / 따라서 / 즉 / 게다가)를 한 문단에 세 번 넘게 쓰지 마라.
- "먼저 — 반면 — 결국" 3단 공식으로 문단을 열지 마라.
- "A가 아니라 B" 대구는 글 전체에서 한 번만.
- 따옴표 강조는 진짜 인용에만. 대시(—)로 덧붙이는 설명을 문장마다 반복하지 마라.

## 대신 이렇게

- 추측을 단정으로 바꾸지 마라. 유보할 것은 유보하되 표현만 바꾼다.
- 없는 사실·수치·발언을 지어내지 마라. 모르면 쓰지 않는다.
- 수식어를 덜어낼 때 내용을 함께 지우지 마라.
