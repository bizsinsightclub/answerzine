# legacy/ — 프로토타입 보관

`Answer_Zine.html`은 빌드 파이프라인 이전의 단일 파일 프로토타입입니다.
**더 이상 발행 산출물이 아닙니다.** 발행물은 `node build/build.mjs`가 만드는 `dist/`입니다.

지우지 않고 남겨둔 이유는 두 가지입니다.

- `design.md`의 수치 상당수가 이 파일에서 실측한 값입니다. 근거 문서 역할을 합니다.
- Paperlogy 4웨이트가 base64로 들어 있어, `assets/fonts/`의 출처가 됩니다.

## 이 파일이 안고 있던 것

`CLAUDE.md` §9에 13건이 기록돼 있고 전부 재현됐습니다. 그중 구조가 만든 사고 하나:

**인쇄 지면이 하드코딩이라 정본이 둘이었습니다.** `issues/2026-w31.json`에서 제외한
영화 편(국내 개봉 전 KOBIS 데이터 인용)이 종이 지면에는 그대로 살아 있었습니다.
