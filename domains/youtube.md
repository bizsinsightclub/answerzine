## 2. 데이터 출처 — 구조적 한계

### 이 도메인에는 1차 출처가 없다

다른 세 도메인은 공식 집계 기관이 있다 (예스24 / 멜론 / KOBIS).
**유튜브 도메인에는 그에 해당하는 것이 없다.** 이유는 둘이다.

1. 유튜브 자체 지표(조회수·급상승)는 **"봤다"의 증거이지 "샀다"의 증거가 아니다.** 이 웹진의 명제는 판매다.
2. 실제 판매·품절을 집계해 공개하는 주체가 없다. 유통사는 선별적으로만 발표한다.

기존 회차(w31)는 이 한계를 그대로 안고 있다. `sourceUrl`이 신문 기사였고, 근거의 상당 부분이 매장 직원 발언이었다. **3조건 검증가능성 기준으로 1점짜리다.**

### "이번 주 급상승 1위"는 이제 존재하지도 않는다

**2025년 7월 21일 유튜브가 인기 급상승(Trending) 페이지와 Trending Now 목록을 폐지했다.**
후속인 YouTube Charts는 카테고리별(음악·팟캐스트·예고편)로 쪼개져 있고, Data API의
`videos.list?chart=mostPopular`도 그날부터 단일 급상승 피드가 아니라 카테고리 차트를 반환한다.

남은 YouTube Charts조차 이 저장소의 기준으로는 쓸 수 없다.

| | |
|---|---|
| 과거 주차 | 내보내기·아카이브 없음 → `whitelist.series: "none"` → **추세선 금지** |
| 읽는 방법 | 목록이 전부 클라이언트 렌더 |
| 범위 | 사실상 뮤직비디오 — 그건 `music` 도메인이 써클차트로 더 잘 본다 |
| 명제 | 조회수는 **"봤다"의 증거이지 "샀다"의 증거가 아니다** |

> **그러므로 이 도메인은 "유튜브의 1위"를 가져오지 않는다. 앞으로도 그럴 계획이 없다.**
> 이 도메인이 가져오는 1위는 **유튜브가 만든 수요를 파는 쪽에서 집계한 1위**다 —
> 올리브영 랭킹 1위, 다이소 품절, 유통사 보도자료의 판매량. 유튜브는 계기 측 증거로만 등장한다.
> 이건 우회가 아니라 이 도메인의 정의다. §1의 "유튜브발 소비"가 그 뜻이다.

### 그래서 이 도메인은 증거를 둘로 나눈다

**계기 측과 결과 측을 서로 다른 출처로 각각 확인해야** 통과한다. 하나만으로는 안 된다.

| 축 | 확인 대상 | 출처 |
|---|---|---|
| **계기** | 영상의 게시일·조회수·확산 시점 | 유튜브 해당 영상 페이지 (조회수·게시일 공개) |
| **결과** | 실제 판매·품절·재고 소진 | 아래 결과 측 출처 중 **하나 이상** |

### 결과 측 출처 (우선순위 순)

| 출처 | 신뢰도 | 비고 |
|---|---|---|
| 유통사 공식 발표·보도자료 (올리브영, 다이소, 편의점 3사 등) | 높음 | 수치가 명시되면 `sourceUrl`로 쓸 수 있다 |
| 네이버 데이터랩 쇼핑인사이트 | 중 | 카테고리 검색·클릭 추이. 판매 자체는 아니다 |
| 제조사 IR·실적 자료 | 높음 | 분기 단위라 주간 서사에는 늦다 |
| 언론 보도 (경제지 유통면) | 중 | **단독으로는 부족.** 계기 측과 반드시 병행 |

### `sourceUrl`에 넣지 않는 것

개인 블로그, 커뮤니티 글, 인플루언서 주장, 매장 직원의 구두 발언.
매장 직원 발언은 **본문의 정황 묘사로는 쓸 수 있지만 `sourceUrl`이 될 수 없다.**

## 3. 이례 판정

### 기준선

**콘텐츠 노출 → 오프라인 소비 전환.** 조회수의 절대 크기가 아니라 **전환이 일어났다는 증거**가 기준이다.

### 판정 기준

| 등급 | 조건 | 이례성 |
|---|---|---|
| 명백한 이탈 | 영상 확산 후 **72시간 이내** 품절·재고 소진이 공개 출처로 확인됨 | 2점 |
| 경계선 | 판매·검색 급증은 확인되나 품절까지는 미확인 | 1점 |
| 통상 범위 | 조회수만 높고 소비 전환 증거 없음 | 0점 (탈락) |

**조회수만으로는 절대 통과시키지 않는다.** 그건 다른 웹진의 소재다.

### 흔한 오탐

- **협찬·광고 영상** — 아래 별도 항목.
- **브랜드 자체 채널 콘텐츠** — 광고와 같다.
- **신제품 출시 주간** — 품절이 마케팅 계획의 일부일 수 있다.
- **한정 수량 판매** — 소량 입고면 품절이 이례가 아니다. 입고 물량을 확인할 수 없으면 다루지 않는다.
- **인위적 품절 마케팅** — 재입고 주기가 지나치게 규칙적이면 의심한다.

### ⚠️ 협찬 영상은 소재로 쓰지 않는다

계기가 광고면 `왜 팔렸나`의 답이 **`광고비를 썼다`** 가 된다. 이 웹진의 명제에서 정면으로 벗어난다.

- 유료 광고 표기(`유료 광고 포함`), 더보기란 협찬 고지, `#광고` `#협찬` 해시태그를 **반드시 확인한다.**
- 표기가 없어도 정황상 협찬이 의심되면 (동일 제품이 여러 채널에 동시 등장, 촬영 구성이 브랜드 소재와 동일) 다루지 않는다.
- **판단이 애매하면 싣지 않는다.** 이 도메인에서 가장 자주 발생하는 탈락 사유다.

## 3.5 기준일 — 영상 게시일 (KST)

- 기준일 = **영상 게시일**. 유튜브는 조회자 기준 시간대로 표시하므로 **KST로 환산해 확인한다.**
- 해외 채널이면 게시 시각이 현지 기준이다. 국내 판매 반응과 붙일 때 하루 어긋날 수 있다.
- 유튜브(`evidence_only`)는 **계기 측 확인 전용**이다. `stat.sourceUrl`로 쓸 수 없다 — 빌더가 차단한다.
- **기준일 ≤ 집계 시작일**을 확인한다. 이 도메인은 전환 속도가 서사이므로 시간 순서가 특히 중요하다.

## 4. stat 블록 표준형

> **`sourceUrl`은 유튜브가 아니라 파는 쪽이다** (§2). 유튜브는 계기 측 증거로만 등장한다.
> 결과 측 출처는 대부분 `snapshot`·`none`이라 **`trend`를 그릴 수 없다.**
> 유통사 보도자료가 여러 시점의 수치를 한 문서에 담고 있으면 그때만 예외이고,
> 그 경우에도 `trendSource`에 각 점의 출처를 적는다 (`CLAUDE.md` §3.4).

```js
{ type: "stat",
  label: "품절까지 걸린 시간",
  value: "영상 게시 26시간",
  basis: "올리브영 온라인 해당 SKU 기준. 직전 재고 소진은 3주가 걸렸다.",
  sourceUrl: "https://…",          // 유통사 공식 발표·보도자료
  sourceLabel: "… 확인하기" }
```

| 항목 | 규칙 |
|---|---|
| `label` | **무엇을 센 값인지 명확히.** 조회수가 아니라 소비 쪽 지표여야 한다. |
| `value` | 배수·증감률·소요 시간. **속도를 드러낸다** — 이 도메인의 핵심은 빠르기다. |
| `basis` | **필수.** 어느 유통사의 무슨 범위이고, 평소와 무엇이 다른지. |
| `trend` | 원칙적으로 **쓰지 않는다.** 한 문서에 여러 시점 수치가 있을 때만. |
| `sourceLabel` | 출처가 매주 달라지므로 매번 새로 쓴다 |

## 7. 집필 주의사항

- **속도가 이 도메인의 서사다.** `며칠 만에`가 아니라 `24시간 만에`, `하루 만에`처럼 구체적 시간을 쓴다.
- 제품을 추천하지 않는다. 효능·품질을 평하지 않는다. **팔린 현상을 다루지 제품을 다루지 않는다.**
- 영상 제작자를 띄우거나 깎지 않는다. 채널명은 계기 특정에 필요할 때만 쓴다.
- 매장 현장 묘사는 정황이다. **정황으로 수치를 대신하지 않는다.** 기존 회차의 매장 직원 발언은 본문 재료였고, `stat`은 별도 출처였다는 점을 유지한다.
- `소비를 조장한다`는 인상을 남기지 않는다. 마지막 문단은 구조를 짚는다.
  기준선: `이제 매출을 움직이는 건 매대 위치가 아니라, 15초짜리 화면이다.`
- 브랜드명을 헤드라인에 넣지 않는다. **본문에서도 최소한으로 쓴다** — 이 도메인은 광고로 읽히기 가장 쉽다.

### 표기 규칙

- 영상 형식: `쇼츠`, `숏폼` (혼용하지 말고 회차 내에서 통일)
- 채널명: 정식 표기 그대로. 개인 실명은 공개 활동명일 때만.
- 유통사·브랜드명: 필요한 최소 횟수만

## 8. 이 도메인의 개선 과제

- **결과 측 1차 출처를 확보해야 한다.** 유통사 주간 발표, 데이터랩 API 등 매주 같은 방식으로 읽을 수 있는 소스를 찾는다. 확보 전까지 이 도메인은 결번이 잦을 것을 각오한다.
- 소재를 못 찾은 주에는 **무리해서 조회수 기사로 채우지 않는다.** `CLAUDE.md` §7.2에 따라 결번 처리하고 보고한다.
- 분기 점검 시 이 도메인이 **연속 4주 이상 결번**이면 도메인 유지 여부를 사용자와 재검토한다.
