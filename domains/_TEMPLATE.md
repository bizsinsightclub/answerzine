# <도메인명> — 도메인 룰셋

> 신규 도메인 추가용 템플릿이다. 복사해서 `<key>.md`로 만들고 **전 항목을 채운다.**
> 빈 항목이나 `TODO`를 남긴 채로 발행하지 않는다. 채울 수 없는 항목이 있다면
> 그 도메인이 아직 성립하지 않는다는 신호다 (`README.md` §2 사전 확인).

## 3. 이례 판정

### 기준선 — 이 도메인에서 "평소"란

무엇과 비교해 이례를 판정하는지 명확히 적는다. 절대값이 아니라 **기대값 대비**여야 한다.

### 이례 판정 기준

| 등급 | 조건 | 3조건 이례성 점수 |
|---|---|---|
| 명백한 이탈 | | 2점 |
| 경계선 | | 1점 |
| 통상 범위 | | 0점 (탈락) |

### 이 도메인에서 흔한 오탐

이례처럼 보이지만 아닌 패턴을 적는다. (예: 정기 이벤트, 재발매, 집계 방식 변경)
