# 카드 사진 (assets/img/covers/)

카테고리 카드(홈 화면) 호버 시 벗겨지며 보이는 사진을 여기 넣는다. 흑백 변환은
CSS가 자동으로 처리하므로 컬러 원본을 그대로 올리면 된다.

## 사진 올리는 법 (GitHub 웹에서)

1. 이 폴더( `assets/img/covers/` )로 들어온다.
2. 우측 상단 **Add file → Upload files** 버튼을 누른다.
3. 사진 파일을 드래그하거나 선택해서 올린다. 파일명은 도메인을 알아볼 수 있게
   짓는다 — 예: `movie.jpg`, `music.jpg`, `youtube.jpg`, `book.jpg`.
4. 하단에 커밋 메시지를 아무거나 남기고 **Commit changes**를 누른다.

파일이 올라오면 그다음은 이 저장소를 관리하는 에이전트가 각 스토리 데이터
(`issues/*.json`)의 `image` 필드에 경로를 연결하고, 실제로 카드 호버 시 사진이
나오는지 확인한 뒤 발행한다 — 이 폴더에 사진만 올려두면 나머지는 자동으로
이어진다.
